Help - how to use this system

  1. Login using the username and password given to you by the clinic administrator.
  2. Register new appointment: from the main menu, choose "Register New Appointment", fill in the patient's details, pick a dentist and treatment type, choose a date/time, then submit. Note down the appointment number shown - the patient will need it.
  3. Search appointment: choose "Search Appointment" and enter the appointment number to view the stored patient and appointment details.
  4. Calculate and print bill: choose "Calculate and Print Bill", enter the appointment number, and press "Calculate bill". Use the "Print bill" button to print a receipt for the patient.
  5. Exit system: use "Exit / Logout" in the top-right corner of the menu screen to safely log out.

For administrators

  1. Manage staff accounts: add or remove receptionist/admin logins.
  2. Manage dentists: add or remove dentists available for booking.
  3. Manage treatment types: add or remove treatments and set their consultation fee.
  4. View reports: see a summary of total appointments, appointments per dentist, and estimated revenue.
