Front Desk

Help & how-to guide

For all staff

  1. Login using the username and password given to you by the clinic administrator.
  2. Register new appointment: fill in the patient's details, pick a dentist and treatment type, choose a date/time, then submit. Note the appointment number shown — the patient will need it.
  3. Search appointment: enter the appointment number to view the stored patient and appointment details.
  4. Calculate and print bill: enter the appointment number and press "Calculate bill." Use "Print bill" for a receipt.
  5. Exit system: use "Exit / Logout" in the sidebar to safely log out.

For administrators

  1. Staff accounts: add or remove receptionist/admin logins.
  2. Dentists: add or remove dentists available for booking.
  3. Treatment types: add or remove treatments and set their consultation fee.
  4. Reports: see total appointments, appointments per dentist, and estimated revenue.
